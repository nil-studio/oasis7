macOS x64 主镜像

当前设备推荐

下载 `oasis7-macos-x64.dmg`，挂载后把 `oasis7 Client Launcher.app` 拖进 `/Applications` 就行。

下载 macOS 主包

Intel x64 macOS 桌面环境。现在还没有单独的 Apple Silicon 包，所以在 Apple Silicon 设备上验证，默认要接受兼容层这个前提。

打开 `.dmg`，拖进 `/Applications`。升级时直接用新的 `.app` 替换旧的，不要把“先删再装”当成会自动保留状态的等价做法。

这个 DMG 还在技术预览阶段，codesign 和 notarization 都还没收完；Gatekeeper 的警告在这件事做完之前都算正常。

这里承诺的是技术预览验证，不承诺“第一次打开完全没系统警告”。如果你本地已经有 `config.toml` 或链执行 world，替换前自己先备份。

当前设备默认会先选 macOS x64；如果你是在替别的机器下载，可以自己切上面的按钮。

Linux x64 Debian 主包

当前设备推荐

下载 `oasis7-linux-x64.deb`，用 Debian/Ubuntu 的软件包安装器安装。Linux 现在统一提供这一条主包路径；运维恢复工具另作为独立资产提供。

下载 Linux 主包

x86_64 Debian 系 Linux 桌面环境（例如 Debian 或 Ubuntu）。当前没有 ARM 或其他 Linux 架构的主包。

用软件包安装器打开 `.deb`，或在 Debian/Ubuntu 上运行 `sudo apt install ./oasis7-linux-x64.deb`。升级时重新安装最新 `.deb`；不要默认以为换安装目录会自动迁移本地状态。

Linux 主包随公开的 `SHA256` 校验文件提供来源辅助验证；这不替代发行版信任链或系统安全策略。

如果发行版不兼容 Debian 包，或设备安全策略阻止安装，请先看发布说明里的最低执行要求；其他发行版特化问题不算默认支持范围。

当前设备默认会先选 Linux x64；如果你是在替别的机器下载，可以自己切上面的按钮。

先确认这条路适不适合你

当前公开入口仅用于技术预览验证，不是公开网页玩家入口。

  • 适合：愿意验证技术预览、反馈 blocker 和安装摩擦的 builder。
  • 不适合：期待直接通过网页加入，或寻找面向普通玩家的正式发售体验。
  • 当前边界：这不是公开网页玩家入口，也不是正式玩家发布；正式公告仍在准备中。
更多校验与升级信息
  • 完整校验文件： oasis7-checksums.txt
  • Linux 默认主包是 `.deb`；运维恢复工具另以带 manifest/checksum 的 `oasis7-linux-x64-ops-tools.tar.gz` 独立资产提供。
  • 升级方式目前很朴素：重新下载最新主包，然后手动覆盖安装或替换；还没有应用内自动更新。
  • 升级前先备份当前启动目录下的 `config.toml`、`.oasis7_launcher_ux_state.json` 和 `output/chain-runtime/<node_id>/reward-runtime-execution-world/`；这些状态现在还是跟着实际启动目录走。
  • Windows 尤其别把“先卸载再重装”当成等价升级路径。当前卸载器会把安装目录一起删掉。

世界规则与玩家边界

世界规则 · 玩家边界

这个世界只有几条不可违反的法律。

它们解释玩家能影响什么，也解释 Viewer 为什么必须把证据和未知状态说清楚。

01 · 持久时间线

时间只向前走

同一个世界沿持续、权威的时间线推进；刷新页面不会抹回已经发生的变化。

02 · 资源代价

没有什么凭空出现

每一份资源都有来源、代价与归属；预览或推荐不会凭空产生结算结果。

03 · 间接能动性

你不能替它们选择

你塑造目标与条件，文明自己行动，也自己承担后果。

04 · 可审计后果

后果可以回看

已发生的变化会留下轨迹；不知道的状态就标为未知，不会假装成功。

普通浏览与刷新不会抹掉已发生的变化；治理恢复属于单独的审计流程。每一份资源都有来源和代价；不知道的状态就标为未知，不会假装成功。详见 《世界规则与玩法系统 PRD》（doc/product/world-rules-core-gameplay/prd.md）。
