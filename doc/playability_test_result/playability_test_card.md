## 标准字段（事实可自动采集 / 判断由评审填写）

- 发布候选 / 版本号：用于横向对比，不可留空。
- 测试场景：如 `新手首玩` / `微循环复测` / `版本对比`。
- 测试者：记录执行者或来源（人测 / AI 辅助）。
- 会话时长：至少记录开始 / 结束时间或总时长。
- 关键操作链路：列出实际执行的主链路；未入局则标明未执行及 blocker，不补造动作。
- 结论标签：`未评审`；完成复核后按证据选择 `继续可玩` / `需观察` / `高优先级阻断`。
- 过程证据：截图、录屏、console、启动日志至少其一；高优问题必须有证据路径。
- 问题摘要：若存在负反馈，必须给出 1 句话摘要。
- 玩家杠杆摘要：必须明确回答“玩家做了什么、世界因此改变了什么、是否打开新决策”；不得只写“世界很活跃 / AI 很忙”。

## 评分口径

本节是问卷答案映射、五维分数和总评的唯一权威，补齐 [#4516](https://github.com/eng-cc/oasis7/issues/4516) 的复算缺口（现由 [#3425 VIEW-4516](https://github.com/eng-cc/oasis7/issues/3425) 跟踪）。采用已有五维结构各占 `20%`，防止题数较多的“节奏与总体体验”隐式获得更大权重。

该补齐在对应文档 PR 合并前为评审提案，合并后用于后续按本版填写的卡片；这是文档评分合同，不宣称已有自动聚合器实现，也不改写历史答卷、标签或发布结论。

### 单题映射

以下分数仅适用于实际回答或已核实且完成评审的观察。原始答案、来源和当前尝试必须保留；无回答、未执行、非法多选的单选题及未评审数据保留未知，不补成 `0`、`3` 或满分。

| 题目 | 映射 |
| --- | --- |
| Q1/Q2/Q4/Q5/Q6/Q10/Q12/Q13/Q15/Q16/Q17/Q18（五档） | 按表中从最负向到最正向的五个选项依次为 `1, 2, 3, 4, 5` |
| Q3/Q8/Q9/Q11（四档） | 按表中四个选项依次为 `1, 7/3, 11/3, 5`；即 `1 + 4 × (选项序号 − 1) / 3`，保留两端并等距映射 |
| Q14（多选） | `好奇/有成就感/有掌控感/想再试一次` 各 `+1`，`无聊/困惑` 各 `−1`，`紧张` 为 `0`；得分 `clamp(3 + 正向选中数 − 负向选中数, 1, 5)`，同一选项只计一次；未回答仍未知，只选“紧张”才得到 `3` |
| Q7（归因） | 不计分、不进维度或总分；`系统随机/系统没听懂 → system_control_gap`，`我策略有问题 → player_strategy_gap`，`运气不好 → variance`，`不确定 → unclear` |

### 维度、总评及缺失

| 维度 | 计分题集合 | 总评权重 |
| --- | --- | --- |
| 理解度 | Q1–Q3 | `20%` |
| 控制感 | Q4–Q6 | `20%` |
| 策略体验 | Q8–Q10 | `20%` |
| 可理解性 | Q11–Q12 | `20%` |
| 节奏与总体体验 | Q13–Q18，含 Q14 转换分 | `20%` |

每维度是其全部计分题的算术平均；总评为五个维度平均，即 `overall = (理解度 + 控制感 + 策略体验 + 可理解性 + 节奏与总体体验) / 5`。不使用 17 题直接平均，也不使用其他 runtime、Player Leverage 或历史 benchmark 指标的权重。

缺任一计分题时，该维度和总评为 `unknown`；可以展示已有答案和覆盖数，但不能丢弃缺失维度后重新归一权重。缺少 Q7 不影响数学分数，但归因覆盖应如实留空；其余必填事实、评审和玩家杠杆证据仍独立校验。

计算保留精确分数或足够精度，展示时四舍五入到小数后两位；按**未舍入值**判档，不用显示值再次计算。

| 未舍入总评 | 数值建议标签 |
| --- | --- |
| `4.2 ≤ overall ≤ 5` | `继续可玩` |
| `3.2 ≤ overall < 4.2` | `需观察` |
| `1 ≤ overall < 3.2` | `高优先级阻断` |
| `unknown` 或越界 | 不生成数值标签，补充回答或核对数据 |

附加规则先于数值建议：`控制感 ≤ 2.5` 或 `理解度 ≤ 2.5` 时，即使总分较高仍建议 `高优先级阻断`；Q18 明确“不会”且开放题给出阻断性原因时，至少建议 `需观察` 并进入问题池；`world_activity_only=yes` 最高只能 `需观察`。保留具体证据和 owner 最终裁决，不让高平均分冲淡独立阻断。总分不替代以下玩家杠杆判定、L4/L5 或发布门禁。

多项附加规则同时命中时取更严格的建议，后出现的 `需观察` 上限不能把已有 `高优先级阻断` 降级。总评为 `unknown` 时不补造数值标签；已经有充分证据的独立阻断仍须记录，不能因缺分而消失。

### 多卡汇总与可复算例

证据包先列出当前候选、访问模式/执行 lane、场景、测试人群及本版评分规则的卡片清单。只对同组、已完成评审且有完整分数的卡片等权平均；分维度与总评都报告有效卡数、未知/排除卡数、原始卡片值和覆盖率。

人测与 AI 来源、不同候选/评分版本/模式/场景分组呈现，不混成一条可比趋势。部分卡片缺分可以保留完整卡片的描述性均值，但该均值不能填补缺失卡片或取消其证据阻断；独立高优问题和玩家杠杆结论逐卡保留。

- 原反例：Q1–6、Q8–10 为 `5`；Q11=`1`、Q12=`5`；Q13–18 为 `3`（Q14 仅选“紧张”）。五维为 `5/5/5/3/3`，唯一总评为 `4.2`，数值建议 `继续可玩`；`69/17` 不属于本合同。最终结论仍取决于已评玩家杠杆与附加规则。
- 判档边界：`3.199 → 高优先级阻断`，`3.2 → 需观察`，`4.199 → 需观察`，`4.2 → 继续可玩`。`4.199` 即使显示为 `4.20`，也仍为 `需观察`。
- 四档第二/第三选项分别是 `7/3` 和 `11/3`，不能先舍入成 `2/4` 后再聚合；缺 Q14 不等价于只选“紧张”。

- 玩家杠杆判定（独立于总评）：
  - 下列 5 项各记 `0/1`：`玩家关键动作明确`、`世界变化可归因到玩家`、`玩家能解释结果`、`结果打开新决策`、`这条链路会促使继续玩`
  - 每项须写明当前尝试的判据与证据引用，可复用同一原始证据；只有五项都完成判断才汇总 `0~5`。时间/progress 推进或提交 ACK 不能直接填五分；ACK 也不能单独确定 `world_activity_only=no`。
  - `player_leverage_score = 0~5`
  - `4~5` => `pass`
  - `2~3` => `watch`
  - `0~1` => `block`
  - 若只能证明“世界有活动 / AI 在运行”，但无法证明玩家让世界发生了什么变化，则必须记 `world_activity_only = yes`，且 `结论标签` 最高只能是 `需观察`。
