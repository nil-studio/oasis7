## 1. 目标、现状与边界

为规范与决策视图提供可追溯文档全局投影，以结构树定位产品与专业设计，以关系详情解释需求如何被设计承接。源 Markdown 拥有条款，客户端只拥有派生索引与个人阅读偏好。遵循[产品四域边界](../../product/README.md)和[专业文档组织规范](../doc-governance/doc-structure-standard.design.md)，不迁移文档、不自动修复正文、不增加文档登记或发布门禁。

文档树使用相同的文件、条款、关系与覆盖语义，两种来源分别取数和保存：

| 入口 | 正文与派生缓存 | 阅读位置 | 能力边界 |
| --- | --- | --- | --- |
| 云端指挥中心 | 读取已配置仓库的固定提交；由云端后端生成不可变快照并保存在 D1 | 云端个人空间，按可信用户、项目、环境及视图隔离 | 不依赖用户电脑在线，不读取未提交文件、私有 context 或本机目录 |
| 本地工作树预览 | 本机 Rust 读取选定工作树，SQLite 保存独立预览缓存 | 本机设备/工作树的独立 namespace | 只在本机呈现未提交与明确纳入的未跟踪文档，不上传正文或把预览当成主线规范 |

本地预览位置不是云端阅读记录的可写副本；同标题、路径或分支不能使两个来源的版本混用。既有本地索引、显式树及阅读恢复的源码/历史证据只证明其已记录范围，完整云端实现和两端体验按 §11 分别验收。

## 3. DES-CC-TREE-001：文件、关系与树投影

来源 adapter 构建文件级 `DocumentNode`，包含 sourceScope、project/repository 身份、基线模式与版本、仓库相对路径、标题、kind、声明 ID、原始生命周期及独立规范化类别/解析状态、内容摘要、snapshot ID 和读取结果。本地预览另含设备/工作树身份及 dirty 状态；云端固定提交不伪造本机字段。稳定文件引用使用来源范围与规范化路径，具体正文由 snapshot/commit 和摘要固定；文档 ID 只作为检索字段，重复 ID 产生诊断，不合并文件。章节沿稳定条款 ID 与准确锚点定位，关系的源/目标 fragment 保留完整路径及源位置。

`DocumentEdge` 保存 from/to、kind（navigation / paired_design / upstream_requirement / reference / successor）、声明位置、源摘要及解析结果（resolved / missing / ambiguous / outside_scope / unread）。只有入口的模块/专题导航、明确配对字段及设计上游/承接表产生相应 typed edge；其他 Markdown 链接为 reference。解析支持相对路径、显式锚点和 Markdown 标题锚点，路径沿仓库治理范围规则；导航按下述大小写/标题合同定位，不继承治理校验的宽松 fragment 大小写匹配；重复锚点不静默选第一项。链接不存在与目标超出本次读取范围分别记录。远端链接仅作为引用显示，刷新不跟随网络抓取。

产品投影固定从产品 README 的四域入口读取模块与专题声明；异常额外模块作为诊断，不自动新增第五域。专业系统投影从专业域入口与模块 design 导航展开，同域工程 PRD 可作为需求关联入口；专题归属来自明确导航，无法定位的文件进入“未归属/待核对”。目录投影按路径组织所有候选 PRD/design，README 仅作为结构入口；类型以根 prd/design 与专题后缀为默认，显式声明冲突保留诊断。

结构节点与文件节点分开，树 occurrence 只引用文件键；一个文件被多个父项引用时显示多个引用入口，详情与计数按文件去重。树展开时维护当前祖先集合，遇到循环展示“循环引用”链接并停止该路径展开；交叉域和多对多配对在详情列为关系，不强行放入唯一父子树。排序沿源导航顺序；无序集合按路径稳定排序。

计数标注快照范围、生命周期筛选和去重口径。配对计数只统计已解析 paired_design，不将普通引用或 upstream_requirement 自动提升为配对；无配对、未读取、明确缺失分别计数。生命周期原样保留源声明（包括 `target-contract` 等专业值），另存规范化的已知类别 proposed/draft/active/superseded/retired；其他已声明值归 other，可按原值筛选，只有缺声明才显示 unknown。规范化只提取状态字段首个完整 token（移除包裹反引号并按大小写归一），首项若为 Markdown code span，只取该完整 code span 的内容；否则以空白、中文/英文分号、逗号及左右圆括号（含全角括号）作为 token 终止符；已知 token 后的说明保留在 raw，不影响类别，例如 draft 后附目标说明归 draft，active 后附 owner 信息归 active，target-contract 保持 other。声明为空或格式歧义时单独标记解析诊断，不猜状态。默认隐藏明确历史类别的叶项，但被当前条款引用时显示历史引用占位。生命周期不决定运行或发布状态。

## 4. DES-CC-TREE-002：读取、快照与失败恢复

云端数据流为“已核实仓库与固定 commit → 完整性可辨的树清单 → 有界 blob 读取 → Markdown/生命周期解析 → 关系校验 → 三种树投影 → D1 候选快照 → 发布指针 → 浏览器”。本地预览使用本机 Git/文件 adapter、SQLite 与有限 IPC。两种 transport 消费同一语义合同和代表性解析样本，UI 不自行扫描、拼接未授权来源或推断权威。

云端先解析用户选定 ref 的完整 commit OID，再按该 OID 列举树和读取 blob；整个快照不再读取浮动 main 正文。递归树响应的截断、分页未完成、对象不可读分别保留，不能把少量固定路径或成功返回的一页宣称为完整文档树。补读限定于已核实仓库和同一提交，不能根据 Markdown 链接自动扩大网络访问；来源白名单、可见性、限额与凭据边界沿[总体设计](command-center.design.md#DES-CC-002)。已提交的 symlink blob、子模块和非文档内容只记录跳过，不当作正文追踪。

本地预览以选定根目录读取 tracked 文件和用户显式纳入的 doc 范围内 untracked Markdown；排除 ignored 文件、私有库、会话及所有符号链接（包括路径祖先中的链接）。每个候选记录 read/skipped/deleted/error 与原因，先列举再读取；未读文件不虚构标题、声明或正文。本机扫描前后复核候选清单、HEAD 和已读内容摘要；变化时丢弃候选，保留旧快照并提示重试。这是有界观察，不提供文件系统锁或固定提交的不可变保证。

文档处理预算为最多 3000 文件、1 MiB 单文件、16 MiB 总正文；单来源刷新总期限 30 秒，单次网络/本机读取最多 10 秒。按 core PRD、工作流主责、结构入口、产品/专业 PRD、其他正文依次读取，同级按路径排序；入口也受预算限制。源 API 分页和 blob 请求计入总期限，超限返回已读范围及有界续读入口，不无限自动追页。覆盖展示候选/已读/遗漏数、实际字节、完整遗漏原因计数及最多 20 条路径样本；空文件计已读，全量遗漏不判空结果。

快照包含基线模式、commit/本机身份、清单摘要、生成时间、每文件摘要和覆盖。完整候选才可成为默认成功快照；partial 独立保留，本次失败或遗漏不覆盖最后成功值。首次没有成功快照时允许显示 partial 并明确限制；用户可显式选择查看部分尝试。节点、边、章节与计数不能混用快照，旧异步请求不能覆盖较新选择。

派生缓存有独立 schema/parser 版本和 namespace；版本不兼容或损坏时只重建对应派生对象，不能清空个人记录、本机工具账本或源文件。缓存重建与格式兼容见 §7、§10；原文、边和覆盖可重建，用户决定、显式关系与阅读位置有独立持久化合同。

本功能不执行 Git fetch、checkout、模型调用或源文档写入。源 Markdown 视为不可信展示数据，拒绝目录逃逸、任意 scheme、脚本和原文命令执行。目标不存在只有在完整列举范围内才标 missing；未列举、未读和范围外分别标记，不能把私有或超预算对象当作缺失设计。

## 5. DES-CC-TREE-003：查询接口与交互恢复

接口是有限的树查询与文件详情读取：tree query 接受获准来源范围、snapshot、view、parent occurrence、cursor、搜索与筛选；返回当前级节点、计数口径、next cursor 和 coverage。详情接受同一 snapshot 下的文件键/fragment，返回章节与明确关系及依据。失效 snapshot 返回可修复错误，不静默跳到当前不同版本。云端通过已授权 HTTP API 读取，本地预览通过受限 IPC 读取；共享语义不要求共用 Rust 二进制或具有本机权限的 WebView。

首次只展开模块层；按需取子节点并虚拟化长列表，分页不裁掉搜索命中的祖先。搜索使用该来源快照的标题、路径、文档/条款 ID 索引，保留祖先与命中标记；隐藏生命周期的命中须提供显式展开入口。配对跳转在详情切换目标并保存返回栈，不修改源文件或确认关系。

云端个人偏好按可信 owner、project、environment、已提交来源范围和视图保存展开位置、已提交筛选、选中文件/章节与滚动位置，以及最近使用的树视图；写入沿云端个人空间的 revision/CAS、幂等和历史合同。本地未提交预览的位置按设备/工作树、基线模式和视图单独保存，只留本机，不进入云端个人偏好。展开位置使用源路径和明确目标组成的稳定导航路由，不保存绑定快照的数字 occurrence 或分页游标；同文件不同父项保留各自路由。标签、行号和数组顺序不作为跨快照的文件身份；同一路由无法唯一匹配时停止恢复，不猜选择。新快照按明确路径重投影；节点或边删除时保留旧位置提示和最近可用祖先，不按相同标题跳到另一文件。章节恢复须核对路径、章节 ID 和内容摘要，无法核对时保留文件及原位置提示，不自动打开其他章节。恢复请求完成前发生的用户视图/项目选择优先，旧异步结果不得抢回界面。偏好丢失可回到根，不影响源或个人决定。

偏好采用独立版本化 personal 记录，与可重建清单及原 Snapshot 分离；读取损坏或未知版本只报告恢复不可用，不删改原记录及其他个人数据。只有实际用户操作才替换可支持版本的偏好，不以启动默认值覆盖不可读记录；保存失败显示提示且保留当前会话位置。路由、展开数量、搜索长度和滚动值须有明确预算，超限恢复有提示，不进行无限遍历。个人记录更新不重置当前树，缓存刷新不删除偏好。

UI 提供 tree/treeitem 语义、展开状态与层级；方向键导航与折叠、Enter 打开详情，IME 组合输入不触发跳转。窄窗口以树/详情两页和返回入口保持阅读上下文；加载、空结果、部分结果与错误分别呈现。数量和预算采用实现后代表性语料验证，不预写性能达标结论。

### 5.1 面向主题的默认阅读与诊断分层

本节定义已发布投影的阅读交互，不增加模型归纳或文档权威。文件清单、主题树与原文详情共用快照和选择状态，避免不同入口解释出不同的关系结论。

直接进入“文档全局”且没有可恢复偏好时，默认显示产品树的四模块入口，专业系统树与其并列可切换。已有用户明确选择的视图优先恢复；从工作详情或准确条款进入时直接打开对应文档、来源版本及关系，不要求先切换树、填写路径或理解扫描器。目录与文件清单放在“按路径查找/检查缺口”入口，仍能查漏；不能作为首次阅读的默认平铺列表。

| 区域 | 默认信息与顺序 | 按需展开 |
| --- | --- | --- |
| 导航 | 产品/专业主题、标题、文档类型及草稿/历史标记；搜索保留祖先 | 目录、文件清单、缺口筛选与完整计数口径 |
| 阅读详情 | 标题与适用范围 → 所选条款正文 → 显式配对/上游及理由入口 → 返回原工作或树位置 | 文件路径、文档/章节完整 ID、摘要、读取字节和原始声明样本 |
| 来源提示 | 所选基线、最后成功读取和影响当前阅读的过期/部分/冲突提示 | 完整覆盖、未归属集合、解析规则及诊断样本 |

正文按安全的标题、段落、列表、表格和代码块阅读层级展示，原始 Markdown 另可查看；不让整页原文预格式化框承担所有正文阅读。链接仍通过受控来源打开，代码和原文命令均不可执行。长正文使用主要阅读区域滚动，避免正文、列表与诊断各占满高度形成竞争滚动区；窄窗口沿 §5 的树/详情往返，不缩小正文掩盖内容。

诊断隐藏只改变信息层级。所选文件未读取、关系歧义、过期快照或范围不完整，必须在受影响内容旁显示原因和具体下一入口；不能把失败显示为空目录、把未解析显示为无设计，或折叠掉判断所需的旧版本。无结果保留当前筛选和范围，并提供清除筛选/查看目录；读取失败保留最后成功内容、版本和重试入口；重复 ID 与多配对仍按原关系合同分别呈现。

新增偏好字段使用独立可选版本化记录，沿 §5/§10 恢复和兼容规则。默认视图不回写覆盖用户旧偏好；外部条款跳转的临时定位与用户保存的长期阅读位置区分，返回时恢复原筛选、焦点和滚动。UI 复用同一文件详情与受控源组件，各入口不复制选择状态或建立另一份解析结论。

## 6. 接口合同与关键运行流程

| 接口 | producer → consumer | 身份与版本 | 顺序/重放 | 成功与错误 | 兼容与预算 |
| --- | --- | --- | --- | --- | --- |
| 刷新 | 浏览器 → 云端后端 → GitHub；本地 UI → Rust → 本机 Git | 获准 sourceScope、基线模式/OID、attempt 与单调 generation | 同一请求复用尝试；新 generation 使旧尝试不得发布 | attempt 状态、当前成功 snapshot 与 coverage；取消/超时不发布候选 | 每来源一个当前发布 generation；30 秒总期限，超限保留旧值 |
| 树/清单查询 | 来源投影服务 → 对应 UI | schemaVersion、snapshot、view、parent、cursor、已提交 filter | 只读无副作用；cursor 绑定来源、快照、视图、层级与筛选摘要 | 分页与 coverage；失效要求重新定位；未知版本 unsupported | 每页最多 100 节点或命中，搜索保留祖先；深度最多 64 |
| 详情与打开源 | 来源服务 → UI / 受限导航 | 文件键、snapshot、fragment、内容摘要 | 原快照优先，打开现行原文另标版本 | read_error、missing、ambiguous、outside_scope 区分 | 单文件预算；导航不授予文件、命令或上传权限 |
| 保存阅读位置 | 登录浏览器 → 云端个人空间；本地预览 → 本机个人设置 | 真实 owner/project/environment 或本机 scope，record revision、mutation ID | 同一幂等请求回读；CAS 冲突保留当前会话位置 | 持久提交才称已保存；断网/超时/冲突各有状态 | 未知记录版本保留且拒绝不安全编辑，不能用默认值覆盖 |

用户刷新先固定来源与 generation，adapter 列举、读取并校验；服务按 §7 发布后 UI 才切换默认树。查询失败不自动启动刷新；切换项目/账号后旧响应只能归原上下文。云端个人偏好查询、保存、搜索与导出始终经过服务端身份和范围校验，来源查询的权限不能代替个人记录权限。

### 6.1 声明与锚点解析

解析使用 CommonMark 事件，代码、引用、嵌套示例与 HTML 注释不产生权威声明。文件头指首个顶层非 H1 标题之前的顶层列表；各字段独立保留源行、原声明和解析完整度。

- `文档 ID`：单个 ASCII 字母/数字及 `-_.:`，最多 256 字节；普通文本或单层反引号均可。字段最多 512 字节，跨行、多条、空或不支持格式均有诊断且不选定 ID。原文最多展示 512 字符，不能称作完整声明。有效 ID 按大小写精确判重复，保留其他文件总数及最多 20 条路径样本；检索可以忽略大小写。未读文件不参加确定性唯一性结论。
- `配对系统设计`：仅文件头精确字段中的 Markdown 链接构成 paired_design；产品 PRD 的顶层二级“文档身份”内精确“配对产品 design”或“配对产品设计”字段同样识别，到同级或更高标题终止。每组最多 32 目标、4096 字节，跨行只取首行链接并标不完整。普通引用与同名文件不产生配对。
- `上游`：仅 design 类型文件头的精确字段构成上游引用；目标 kind 沿同次清单，需求与设计引用分别显示。预算与配对字段分别计算，不用上游设计冒充需求或配对。
- 承接表：仅已读 design 中标题可见文本为“需求承接与分配表”的顶层表格，可带 ASCII 数字/点/空白的编号前缀。唯一的“上游条款”与“本设计条款”列产生两组显式链接，其他列保留样本；代码/普通表格/验证表不产生承接。每文件最多 32 行、两侧合计 64 链接，每行 4096 字节、样本 512 字符。缺表头、重复列、无可识别链接或超限均标不完整；只有明确 `无` / `none` / `None` 表示声明无链接。引用式链接、转义竖线及 inline code 由解析器处理，不按原文竖线拆列。

标题锚点来自可见文本：支持 Setext，转小写，保留 Unicode 字母/数字与连字符，移除格式和其他标点，以连字符连接空白。显式 HTML `id` 按大小写精确匹配，支持单/双引号和前置属性；raw-text HTML 块不解析内部伪锚点。重复显式/标题锚点及二者冲突都标 ambiguous，不静默选首项或追加编号。

目标只在同次清单和已读正文中解析，不能沿链接追加磁盘/网络读取。无 fragment 的已读文件可 resolved；fragment 唯一匹配才可跳转。缺 fragment 标 missing_fragment，已列举删除标 missing，其他读取遗漏标 unread，未纳入/外部/越界/不安全目标标 outside_scope。跳转再次核对目标路径、章节 ID 与内容摘要；无 fragment 进入首个可读章节，空文件不伪造章节。邻接标题的显式锚点属于该标题，正文/表格锚点属于其所在章节。缺解析字段或未知旧结果表示尚未解析，不解释为无关系。

### 6.2 筛选、分页与历史引用

文件清单包含全部已列举候选；目录由 PRD/design 与结构入口投影。根 parentPath 为空，其他路径必须规范化，拒绝绝对路径、空段、`.` / `..` 和超过 4096 字节的输入。只读当前层时仍保留所有匹配文件的祖先入口，深度超限显示原因，原清单中的深层文件不消失。

搜索按标题、路径、文档 ID 和条款 ID 匹配，读取状态、类型、生命周期和配对缺口共同作用于目标文件。所有数量在已应用范围去重计算，不随当前页裁剪；响应显示实际筛选。未提交输入不改变当前结果、下一页或重试。来源、视图、父路径或筛选改变使旧 cursor 失效；个人记录变化不重置当前来源树。

生命周期支持 all、current、已知规范化类别、other、unknown 及原始声明 `raw:` 精确筛选；输入最多 1024 UTF-8 字节，拒绝未知值与空 raw。current 只隐藏明确 superseded/retired，缺声明、未读或歧义保留且不称为当前已生效。类型支持 all/prd/design/entry，其他值拒绝。配对缺口使用 unpaired/unparsed/missing/unread/ambiguous/outside_scope/incomplete，缺口允许重叠，不能由 unpaired 推断设计不存在。缺元数据、未知解析结果和缺少定位的 resolved 均须保留诊断。

当前范围内已读、非明确历史的来源引用到已核实历史目标时，保留“历史引用占位”和祖先；来源必须与目标摘要及准确锚点一致，未知来源生命周期不因此变成 active。占位显示不同来源文件总数及最多 20 条排序样本；不递归传播历史引用，不因筛选掉来源文件而抹去已核实关系。普通引用、后继或未支持格式只能按实际已解析 typed edge 使用，不通过标题推断。未解析范围单独显示，不能把有限解析结果称为全仓引用图。

### 显式产品与专业导航投影

产品根只消费 `doc/product/README.md` 的“四大产品模块”入口与四个根 PRD；根 PRD 的“活跃产品专题”区间产生专题导航，到同级或更高标题结束。专业根只消费 `doc/README.md` 的“工程模块入口矩阵”，支持明确 Markdown 链接与反引号仓库路径；模块内使用明确导航节和文件级索引。目录名称只解析其 README 候选，不将物理目录提升为语义归属。普通正文、职责表和过程说明不产生树边。

导航声明保留标签、源行、目标与诊断；每文件最多 256 条，展开深度最多 64。多父保留各自 occurrence，文件详情与计数去重；祖先集合检测循环并停止该路径，跨域目标作为边界引用，不继续展开或成为本域归属。未被显式导航到的范围内文件在“未归属/待核对”按路径查漏，不等于缺设计。缺 navigation 字段或来源未读时保留未知，不构造空的四域假树。

首次产品树以可辨认的四域入口显示；已保存视图与准确条款直达优先。域展开与原文阅读使用不同动作，长树按需分页。行内显示库图标、文档类型、标题和适用的生命周期；路径、完整 ID 与解析样本按需展开，影响所选内容的错误不可折叠隐藏。图标只由已知路径/类型选择，未知使用通用文件。树提供 tree/treeitem、层级、展开状态与单个游走焦点；上下/Home/End 导航，右键展开或进入子项，左键折叠或回父项，Enter 阅读，结构项 Enter/空格展开，IME 输入不触发导航。窄屏保留树/详情往返、原焦点与筛选。

### 两棵显式树的个人阅读恢复

持久化保存稳定路由而非 snapshot occurrence 或 cursor：逐步绑定源路径、目标路径与声明 destination/fragment，多父路线分别保留；重复等价声明造成歧义时停止恢复。每路由最多 64 步、每偏好最多 128 条展开路由、整个树偏好最多 256 KiB；滚动值有限且有范围，字符串沿查询预算。云端与本机使用独立存储范围，跨设备只恢复已在云端成功保存的已提交来源位置。

启动先读取最近视图与偏好，不把默认值回写；用户的新选择优先于迟到恢复。节点删除、关系歧义或筛选不可见时返回最近可用祖先与提示，不能猜同名文件或清空筛选。章节仅在路径、ID、摘要相符时恢复，无法核对时保留原位置并由用户选择。保存失败/冲突保留当前会话位置，未知未来版本不覆盖；显式重置只作用于选定可支持范围并沿个人记录历史合同留痕。刷新缓存不删除阅读偏好，私有本地预览路径不进入云端导出。

## 7. 状态、事务与持久化

来源服务拥有 attempt 状态，数据库拥有提交事实；UI 接受请求不等于快照发布。快照状态与文档生命周期分别记录。

| 对象/状态 | 触发与转移 | 拒绝/终态及阅读结果 |
| --- | --- | --- |
| queued → reading → validating | 明确刷新、身份/基线有效，取得该 sourceScope 的 generation 与有界租约 | 无效范围/schema 拒绝；租约和进度持久化，不能只依赖 Worker 内存 |
| validating → complete | 已列举完整清单、候选摘要与覆盖校验成功，仍是当前 generation | 原子发布 manifest 与 current pointer 后才为 published；事务失败不改指针 |
| reading/validating → partial | 已知读取/权限/预算遗漏 | 保存独立 partial attempt，保留旧成功快照；首次无成功值时明确 partial |
| 非终态 → failed/cancelled | 超时、取消、源变动或不可恢复错误 | 不改 current pointer；禁止旧 generation 或过期租约发布 |
| current → stale → current | 刷新失败/partial；之后新完整候选发布 | stale 只表达新鲜度，节点仍保留原版本 |

云端以有界批次写入不可变候选分块，校验完整清单、节点/边数及摘要后，使用 CAS 原子提交发布 manifest 和 current pointer；读取只追踪已发布指针。不能把整棵 16 MiB 树描述为一个天然原子网络请求或将半写候选作为当前数据。本地可以在 SQLite 事务写入完整快照及指针，但遵守同一可见性合同。发布回执丢失时先查原 attempt/current pointer，不重复创建不同身份；旧请求、已取消选择和过期租约不能覆盖较新结果。

异常结束的非终态 attempt 在租约过期或重开核对后标 failed/abandoned，保留最后成功指针，不自动重放。每来源保留 current、最近 partial 与最近 20 条终态尝试元信息；清理只删除无有效读取/发布引用的候选。过期 snapshot 查询返回 expired；不把失败、账号撤权或暂时读不到视为允许清空数据。

节点/关系/coverage/attempt 是可重建缓存，个人阅读偏好归用户存储，本机工具账本独立。元信息不含凭据、私有会话或本机资料。persisted 以持久提交为据，published 以已验证指针为据，两者均不证明规范语义正确或产品功能已实现。

## 8. 部署、安全与运行约束

云端在 Sites 后端读取已配置 GitHub 来源、处理快照并存储 D1，浏览器不持有来源密钥。用户、项目、来源可见性与个人记录授权分别核对；交互读取非公开来源必须有当前用户对应的有效来源授权，其缓存不能通过公开查询复用，也不能仅因服务器持有凭据而向任意登录者开放。后台服务身份仅可刷新明确配置的公开来源，不能读取非公开来源或冒充用户保存个人偏好；身份、撤权及缓存规则沿[总体设计](command-center.design.md#DES-CC-011)。

本地使用普通用户 Rust 和打包 UI，不向远程页面开放 Tauri IPC，不建立云端到 localhost 的通道。预览只读取本机选定范围，拒绝文件及祖先 symlink、私有库和替换身份；云端提交模式不读取本地目录。任何正文或链接均不授予执行、Git 写入或上传权限。某来源失败只影响依赖它的范围；云端失联不影响本机工具，本机离线不阻止已提交来源阅读。

## 10. 格式兼容与恢复

缓存格式、解析器、查询 schema 与个人偏好格式分别版本化。未知缓存可停止消费并重建；未知个人格式保留原值并拒绝不安全编辑，不能删库恢复。云端 API 与本机 IPC 各自显式拒绝不支持版本，不要求同步升级所有客户端才能识别失败。

兼容读取和新增可选字段不得把“未解析”改成“没有关系”。派生快照发布失败继续使用最后成功版本；回退应用仅恢复兼容的读取/写入范围，不倒写旧格式覆盖新个人数据。持久格式升级、备份恢复及 D1 发布兼容遵循[总体设计](command-center.design.md#DES-CC-017)，具体执行步骤和结果归迁移 Issue/PR。

文档缓存重建不改变源 Markdown、个人决定、已关闭问题或工具操作。云端读取历史提交与恢复个人阅读位置不授予本机文件访问；本机旧记录中的私有排除标记持续生效。不存在云端/本地同类偏好的自动双写或隐式整库上传。

## 12. 长期风险与设计取舍

文档结构不是统一 schema，解析器只承诺明确支持的声明；不支持的标题/列名/普通引用保留诊断，并通过目录与原文查漏。文档 owner 负责规范语义，runtime_engineer 负责解析与范围错误，不能以模型猜测填补确定性关系。

完整仓库可能超过预算，平台限额、源可见性和网络中断也会缩小可读窗口。保持预算、partial 与 last_success 可见；扩大容量应有代表性语料与真实环境测量，不能因为切换宿主便声称无限规模。云端副本不代替 GitHub 权威，本机预览不自动成为已提交主线，个人阅读偏好也不表示用户已经认可条款。
