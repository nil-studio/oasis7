Oasis7 通用账号服务

环境：{{ENVIRONMENT}} · 独立运行在 Cloudflare Workers

连接与 Skill

MCP 接口：本站 /accounts/mcp，使用管理员提供的 Bearer token。

阅读或下载完整 SKILL.md →

将 Skill 地址交给你的 Agent，并在连接器中私密配置认证。页面不收集或展示密钥。

四步使用

  1. accounts 查看授权账号。
  2. open 选择账号并建立有截止时间的会话。
  3. describe 查询会话对应的公开账号信息。
  4. close 关闭会话，额度耗尽时仍可关闭。

工具名：account_service_call。详细参数、结果及错误处理见完整 Skill。

环境与权限

测试与正式环境分别保存账号、凭据、会话和额度。请勿跨环境复制正式凭据。

服务不依赖本机或游戏世界，不返回原始账号凭据，不执行第三方登录。账号配置与轮换由管理员完成。
